# رفيق القرآن

رفيق القرآن is a Flutter Islamic app.

Core decisions:
- Arabic + English from the beginning.
- Android first, iOS later.
- Feature-based Flutter architecture.
- Riverpod for state management.
- Drift/SQLite for local database.
- SharedPreferences for small settings.
- Firebase from the beginning for optional login and sync.
- Guest mode is local-only.
- Logged-in mode is local-first, then Firebase sync.
- Quran source should be Quran Foundation / Quran.com if access is free/approved.
- Prayer times source should be AlAdhan API.
- Adhkar should be local JSON from trusted source.
- Quran, tafsir, and adhkar content must never be generated by AI.
- Daily Quran reminders must not be reduced even if the user ignores them.

# رفيق القرآن

رفيق القرآن is a Flutter Islamic app.

Core decisions:
- Arabic + English from the beginning.
- Android first, iOS later.
- Feature-based Flutter architecture.
- Riverpod for state management.
- Drift/SQLite for local database.
- SharedPreferences for small settings.
- Firebase from the beginning for optional login and sync.
- Guest mode is local-only.
- Logged-in mode is local-first, then Firebase sync.
- Quran source should be Quran Foundation / Quran.com if access is free/approved.
- Prayer times source should be AlAdhan API.
- Adhkar should be local JSON from trusted source.
- Quran, tafsir, and adhkar content must never be generated by AI.
- Daily Quran reminders must not be reduced even if the user ignores them.

Firebase configuration status:
- Configured on 2026-05-24 for Firebase project `rafeeq-alquran`.
- Android package/application id is `com.yousefapps.rafeeq_alquran`.
- `android/app/google-services.json` exists and matches the Android package.
- `lib/firebase_options.dart` exists and was generated by FlutterFire CLI.
- Firebase Core initializes before `runApp` through `lib/core/firebase/firebase_initializer.dart`.
- Firebase Auth email/password code exists for sign in, account creation, sign out, and session watching.
- Email/Password must be enabled in Firebase Console.
- Firestore sync adapters, Firestore security rules, Cloud Functions deployment, and other Firebase products are separate later tasks unless explicitly implemented.
